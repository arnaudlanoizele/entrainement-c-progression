# C Programming — Learning Roadmap

## 🇫🇷 Présentation

Ce dépôt présente mon parcours d'apprentissage progressif du langage C, organisé en huit niveaux de difficulté.

Mon objectif est de développer une compréhension approfondie de la programmation, de renforcer ma logique algorithmique et d'acquérir une véritable autonomie dans la résolution de problèmes.

Chaque niveau comprend des exercices pratiques, des exercices de révision et une validation des connaissances avant de passer au niveau suivant.

## 🇬🇧 Introduction

This repository presents my progressive C programming learning journey, organized into eight difficulty levels.

My goal is to develop a deep understanding of programming, strengthen my algorithmic thinking, and become independent in problem-solving.

Each level includes practical exercises, revision exercises, and knowledge assessments before moving on to the next level.

## 🎯 Learning objectives / Objectifs pédagogiques

- Develop algorithmic thinking — Développer la logique algorithmique.
- Understand memory management — Comprendre la gestion de la mémoire.
- Write clean and structured code — Écrire un code propre et structuré.
- Improve problem-solving skills — Améliorer la résolution de problèmes.
- Develop programming autonomy — Développer son autonomie en programmation.
- Improve technical English — Améliorer son anglais technique.

## 🧠 Learning methodology / Méthode d'apprentissage

1. Progressive learning — Apprentissage progressif.
2. Practical exercises — Exercices pratiques.
3. Error analysis and correction — Analyse et correction des erreurs.
4. Targeted revision — Révisions ciblées.
5. Independent problem-solving — Résolution autonome.
6. Final assessment — Évaluation finale.
